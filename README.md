# Snake L1

Projet de jeu Snake en C avec une interface SDL2.

## Pré-requis

- GCC ou Clang
- GNU Make
- SDL2 et `sdl2-config`

## Compiler et lancer

Depuis le dossier `Sources/` :

```bash
make
./projet
```

Pour une compilation optimisée :

```bash
make nowerror
./projet
```

Pour nettoyer les fichiers générés :

```bash
make clean
```
