◆ score_type

enum score_type

Type utilisé pour représenter les différents scores.

Valeurs énumérées
SC_MAIN 

Le score principal du serpent.

SC_STUDENTS 

Le nombre d'étudiants que le serpent a mangés.

SC_LENGTH 

La longueur du serpent lorsqu'il est mort.

SC_VISITED 

Le nombre de cellules que le serpent a visitées avant de mourir.

SC_TIME 

Le temps que le serpent a passé en vie (donné en secondes).

SC_SIZE 

Le nombre de types de scores.

Alloue un nouveau score_table sur le tas.

Remarques
Les scores des serpents ne sont pas initialisés (la valeur booléenne filled est définie sur false pour chaque score). Les scores seront remplis après chaque jeu joué.

Met à jour le score d'un seul serpent dans le jeu.

Le score du serpent est mis à jour après que le serpent meurt dans le jeu.

Remarques
Vous devez appeler cette fonction dans implement_turn_all_snakes défini dans project_game.h après qu'un serpent meurt.
Paramètres
stLe score_table.
iL'index du serpent dans le jeu (dans le plateau).
sLe serpent qui est mort.
tLe temps que le serpent est resté en vie avant de mourir (donné en secondes).

Le tableau des scores dans le score_table doit être trié par ordre décroissant du type de score donné en paramètre.
