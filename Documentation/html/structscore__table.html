Description détaillée

Type utilisé pour représenter les scores de chaque jeu dans une série de jeux.

Dans l'interface, il est possible de créer une série de plusieurs jeux consécutifs. Ce type est utilisé pour stocker les scores de chaque serpent dans chaque jeu de la série ainsi que les scores finaux de chaque serpent (la somme des scores du serpent dans chaque jeu).

Le tableau des scores est un tableau à deux dimensions de taille nb_snakes x (nb_games + 1). Si i est l'index d'un serpent (dans le tableau des scores) et j < nb_game est l'index d'un jeu, alors scores[i][j] contient un pointeur vers le score du serpent i dans le jeu j (qui sont remplis après que ce jeu soit joué). De plus, scores[i][nb_game] contient un pointeur vers le score final du serpent i : la somme des scores du serpent dans chaque jeu (qui est rempli après que tous les jeux soient joués).

Remarques
Les serpents ne sont pas nécessairement stockés dans le même ordre que dans le jeu (cela est dû au fait qu'il est possible de trier les tableaux de scores selon l'un des types de scores). La correspondance avec les indices des serpents dans le jeu est donnée par les tableaux game_to_score et score_to_game.
