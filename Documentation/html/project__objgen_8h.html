Description détaillée

Générateurs d'objets.

Ce sont les fonctions utilisées pour générer de nouveaux objets sur le plateau. Une fonction génératrice d'objets prend en entrée le jeu et remplit son plateau avec un ou plusieurs objets.

Pour générer un nombre aléatoire, utilisez la fonction "int rand(void)" de la bibliothèque standard. Pour obtenir un nombre aléatoire entre 0 et N, utilisez "rand() % (N+1)".

Remarques
Vous devez écrire les fonctions génératrices. En revanche, vous ne devez PAS les appeler vous-même. En effet, les stratégies sont appelées dans la boucle de jeu qui est déjà écrite. Chaque tour de la boucle de jeu consiste en les quatre étapes suivantes :
  1. Utiliser une fonction de génération pour générer de nouveaux objets (la fonction est choisie lors de la création du jeu).
  2. Mettre à jour les directions de déplacement des serpents contrôlés par les joueurs en fonction des entrées du clavier.
  3. Appliquer la fonction de stratégie pour mettre à jour les directions de déplacement des serpents contrôlés par l'IA (les fonctions sont choisies lors de la création du jeu).
  4. Implémenter le tour pour tous les serpents en appelant la fonction "implement_turn_all_snakes".

Documentation du type de l'énumération

◆ generator

enum generator

Noms internes des générateurs d'objets disponibles.

Pour ajouter un nouveau générateur, vous devez ajouter un nouveau nom ici, à la fin avant OGEN_SIZE. Ensuite, vous devez compléter les trois étapes suivantes :

  • Écrire la fonction génératrice correspondante.
  • Ajouter la fonction à la fin du tableau generator_funs dans project_objgen.c (il contient toutes les fonctions génératrices).
  • Ajouter le nom à la fin du tableau generator_names dans project_objgen.c (il contient tous les noms des générateurs). Cela est utilisé pour afficher le nom du générateur dans l'interface.

◆ gen_ten_percent()

void gen_ten_percent ( game * g)

Générateur de dix pour cent.

Assure que dix pour cent des cellules vides sont toujours remplies d'objets aléatoires. Si le pourcentage de cellules remplies tombe en dessous de dix pour cent, le générateur remplit des cellules vides choisies aléatoirement avec des objets aléatoires jusqu'à ce que le pourcentage soit de dix pour cent.

Paramètres
gLe plateau.

◆ gen_student_invasion()

void gen_student_invasion ( game * g)

Générateur d'invasion des étudiants.

Assure que vingt pour cent des cellules vides sont toujours remplies d'étudiants. Si le pourcentage de cellules remplies tombe en dessous de vingt pour cent, le générateur remplit des cellules vides choisies aléatoirement avec des étudiants jusqu'à ce que le pourcentage soit de vingt pour cent.

Attention
Lorsqu'ils sont mangés, les étudiants peuvent augmenter considérablement la longueur des serpents. Avant d'utiliser ce générateur, assurez-vous que la fonction utilisée pour consommer la nourriture gère l'erreur qui peut survenir lorsque la longueur totale du serpent devient "trop élevée".
Paramètres
gLe plateau.
