Description détaillée

Paramètres.

Macros pour les paramètres suivants :

  • Activation de certaines fonctionnalités de débogage.
  • Dimensions de la fenêtre.
  • Paramètres par défaut pour les jeux. Ce sont les paramètres utilisés si un jeu rapide est lancé.

◆ WINDOW_SCREENWIDTH

#define WINDOW_SCREENWIDTH   1820

Supprime le message à l'écran lors de la mise en pause du jeu. Décommentez pour activer.

Si cette macro est définie, le message à l'écran qui apparaît lorsque le jeu est en pause sera supprimé. Cela donne un meilleur aperçu du plateau de jeu à des fins de débogage.

Active le débogage des serpents. Décommentez pour activer.

Si cette macro est définie, les cellules marquées comme remplies par un serpent seront surlignées en blanc dans l'application.

Active le premier débogage pour les cellules vides. Décommentez pour activer.

Si cette macro est définie, les cellules listées comme vides dans le tableau empty_cell_listing seront surlignées en jaune dans l'application.

Active le deuxième débogage pour les cellules vides. Décommentez pour activer.

Si cette macro est définie, les cellules marquées comme vides dans le tableau empty_cell_indices seront surlignées en bleu dans l'application.

Active le débogage des masques. Décommentez pour activer.

Si cette macro est définie, le masque sélectionné sera affiché sur le terminal (en appelant la fonction print_mask que vous devez écrire) avant le lancement du jeu.

Dimension horizontale de l'application en pixels (par défaut = 1820).
