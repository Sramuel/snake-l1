Redimensionnement d'un masque.

Conversion d'un masque dont les dimensions sont arbitraires pour lui donner les dimensions souhaitées.

Attention
Le masque doit être redimensionné aux nouvelles dimensions. Le nombre de cellules masquées doit être mis à jour. Au moins une cellule doit être non masquée.

◆ read_mask()

mask * read_mask ( const char * path)

Génération d'un masque à partir d'un fichier.

Attention
Le fichier doit contenir une représentation ASCII de la grille :
  • Le caractère X correspond à une cellule masquée.
  • Tout autre caractère indique une cellule non masquée.
Remarques
Des exemples de tels fichiers sont donnés dans le répertoire "Masks".
Attention
Le fichier doit contenir un rectangle parfait (toutes les lignes doivent avoir la même longueur). Le masque doit contenir au moins une cellule non masquée. Si le fichier ne respecte pas ces conditions, la fonction retourne NULL.
Renvoie
Le masque lu dans le fichier.
Paramètres
pathChaîne contenant le chemin vers le fichier.
