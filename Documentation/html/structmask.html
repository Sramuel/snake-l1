Description détaillée

Type utilisé pour représenter un masque.

Remarques
Les cellules sont indexées par des entiers allant de 0 à hsize*vsize-1. Elles sont ordonnées ligne par ligne de haut en bas. La cellule d'index 0 est dans le coin supérieur gauche. Les cellules allant de 0 à hsize-1 constituent la première ligne en haut de la grille, les cellules allant de hsize à 2*hsize-1 constituent la deuxième ligne, et ainsi de suite.
Attention
Nous supposons toujours qu'un masque contient au moins une cellule non masquée (cette propriété doit être vérifiée lors de la lecture d'un fichier de masque).
