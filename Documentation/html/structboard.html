Description détaillée

Le type utilisé pour représenter un plateau.

Un plateau est une grille rectangulaire de cellules. Les cellules du plateau sont indexées linéairement ligne par ligne, de gauche à droite et de haut en bas. Si le plateau a hsize colonnes et vsize rangées, la première cellule (dans le coin supérieur gauche) a l'index 0, la cellule à sa droite a l'index 1, et ainsi de suite. La dernière cellule (dans le coin inférieur droit) a l'index (hsize * vsize - 1).

Chaque cellule du plateau peut être masquée (c'est-à-dire qu'elle ne peut pas être occupée par des serpents ou des objets). Les cellules masquées sont indiquées par le tableau masked. Si la cellule avec l'index i est masquée, alors masked[i] est vrai; sinon, masked[i] est faux.

Le plateau contient également un tableau d'objets qui indique le contenu de chaque cellule non masquée. Pour chaque i, objects[i] est l'objet contenu dans la cellule avec l'index i. L'objet peut être EMPTY (cette valeur spéciale indique que la cellule est vide), SNAKE (cette valeur spéciale indique que la cellule est occupée par une section de serpent), ou l'un des autres objets définis dans l'énumération object. Si la cellule avec l'index i est masquée, alors objects[i] est indéfini (sa valeur est sans importance).

Le plateau contient également deux tableaux de directions qui indiquent les directions que les serpents ont utilisées pour entrer et sortir des cellules. Pour chaque i, si la cellule avec l'index i contient une section de serpent (comme indiqué par objects[i]), alors indirs[i] est la direction que le serpent a utilisée pour entrer dans la cellule, et outdirs[i] est la direction que le serpent a utilisée pour sortir de la cellule. Si la cellule avec l'index i ne contient pas de section de serpent, alors indirs[i] et outdirs[i] sont indéfinis (leurs valeurs sont sans importance).

Enfin, le plateau maintient également une liste de cellules vides pour un accès rapide (ce sont les cellules non masquées d'index i où objects[i] est EMPTY). La variable empty_cells_count indique le nombre de cellules vides. Toutes les cellules vides sont listées dans le tableau empty_cells_listing aux indices 0, 1, 2, ..., empty_cells_count - 1 dans un ordre arbitraire (le tableau lui-même est de taille hsize * vsize). Le tableau empty_cells_indices est indexé par les indices des cellules (0, 1, 2, ..., hsize * vsize - 1), pour chaque i, si la cellule avec l'index i est vide, alors empty_cells_indices[i] est l'index de la cellule dans le tableau empty_cells_listing qui contient i; sinon, empty_cells_indices[i] est -1.
