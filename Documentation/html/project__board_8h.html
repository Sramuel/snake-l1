◆ object

enum object

Type énuméré utilisé pour représenter tous les objets pouvant être placés dans une cellule du plateau.

Remarques
Le premier objet est EMPTY, qui représente une cellule vide. Le deuxième objet est SNAKE, qui représente une cellule occupée par une section de serpent. Les autres objets représentent les différents types de nourriture pouvant être placés dans une cellule pour que les serpents les ramassent.
Valeurs énumérées
EMPTY 

Cellule vide.

SNAKE 

Section de serpent.

APPLE 

Pomme (1 point + 1 longueur)

CHERRY 

Cerise (2 points + 2 longueurs)

BANANA 

Banane (3 points + 3 longueurs)

GRAPES 

Raisins (4 points + 4 longueurs)

PINEAPPLE 

Ananas (5 points + 5 longueurs)

STUDENT 

Étudiant (20 points + double longueur)

CHILI 

Piment (augmente la vitesse, si pas au maximum)

MUSHROOM 

Champignon (diminue la vitesse, si pas au minimum)

OBJECT_SIZE 

Nombre d'objets.

◆ swap_empty_cells()

void swap_empty_cells ( board * b,
int i1,
int i2 )

Échange les positions de deux cellules vides dans le tableau empty_cells_listing qui liste les cellules vides.

Remarques
Cette fonction ne modifie pas le plateau représenté. Elle ne fait que changer l'ordre dans lequel les cellules vides sont listées. Cela est parfois nécessaire pour modifier le tableau empty_cells_listing. Par exemple, retirer une cellule de la liste des cellules vides se fait en échangeant la cellule avec la dernière cellule du tableau puis en décrémentant empty_cells_count.
Paramètres
bLe plateau.
i1L'index de la première cellule dans empty_cells_listing.
i2L'index de la deuxième cellule dans empty_cells_listing.

◆ fill_cell_board()

void fill_cell_board ( board * b,
int i,
object obj )

Remplit une cellule du plateau avec un objet.

Si la cellule contient déjà un objet, la fonction ne fait rien. Si la cellule était vide, elle doit être retirée de la liste des cellules vides. Dans ce cas, empty_cells_count, le tableau empty_cells_listing et le tableau empty_cells_indices doivent être mis à jour en conséquence.

Remarques
La fonction génère une erreur si l'objet est EMPTY (on ne peut pas remplir une cellule avec un objet vide car il sert à indiquer une cellule vide).
Paramètres
bLe plateau.
iL'index de la cellule.
objL'objet.

◆ empty_cell_board()

void empty_cell_board ( board * b,
int i )

Vide une cellule du plateau.

Si la cellule était vide, la fonction ne fait rien. Si la cellule contenait un objet, elle est vidée dans le tableau objects du plateau. La cellule doit être ajoutée à la liste des cellules vides. Dans ce cas, empty_cells_count, le tableau empty_cells_listing et le tableau empty_cells_indices doivent être mis à jour en conséquence.

Paramètres
bLe plateau.
iL'index de la cellule.
