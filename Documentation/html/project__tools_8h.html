Description détaillée

Outils.

Quelques macros que vous pouvez utiliser dans votre projet. Contient également la fonction get_time_counter. Elle retourne le temps écoulé depuis le début d'un jeu en cours (en millisecondes). C'est la fonction que vous devez utiliser pour calculer le temps qu'un serpent a passé en vie lors du remplissage d'une entrée dans le tableau des scores.

Remarques
Vous ne devez PAS modifier ce fichier.
